# TacviewTCPlink 代码框架说明

## 一、设计目标

模块只解决一个问题：把任意上游数据源转换后的对象状态可靠地交给 Tacview。

核心边界是 `tacview::ObjectState`。上游可以是运动学模型、完整飞行动力学仿真、UDP、串口、共享内存、数据库或 CSV；只要最终填写这个结构，就不需要了解 ACMI、Winsock 或线程。

```text
任意数据源
    │ 适配为 ObjectInfo / ObjectState
    ▼
tacview::Tacview（公开门面）
    ├── 输入校验
    ├── 对象注册表与最新状态
    ├── 有界异步队列
    ├── AcmiEncoder
    ├── TCP 监听与多客户端广播
    └── 可选 .acmi 文件记录
           │
           ├── Tacview 实时显示
           └── Tacview 文件回放
```

## 二、各文件职责

### `include/tacview/Tacview.h`

稳定的公共接口。包含固定单位的数据结构、启动配置和 `Tacview` 门面类。通过 PImpl 隐藏 Winsock、线程和容器，使用者的代码不会受到内部实现变化影响。

### `include/tacview/AcmiEncoder.h`

底层无状态编码接口。普通使用者无需调用；它公开出来是为了测试、扩展特殊 ACMI 属性或独立生成文本。

### `src/AcmiEncoder.cpp`

负责：

- ACMI 2.2 文件头；
- 时间帧 `#time`；
- 对象定义；
- 对象位置与姿态更新；
- 对象删除；
- 属性字符串中的分隔符清理。

它不打开文件、不创建线程，也不访问网络，因此可确定性测试。

### `src/Tacview.cpp`

负责运行时状态：

- 初始化和清理 Winsock；
- 监听 TCP 端口；
- 发送 Tacview 实时遥测握手；
- 维护多个客户端；
- 保存对象元数据和最新状态；
- 将调用线程提交的数据放入有界队列；
- 在发送线程中广播并记录；
- 新客户端连接时补发 Header 和当前快照；
- 拒绝非法输入并记录最近错误。

## 三、线程模型

```text
调用方线程                 accept 线程              send 线程
add/update/remove ──队列──▶                         编码结果广播
                          接受客户端 ──────────────▶ 客户端列表
                          发送握手和当前快照
```

调用方不会直接执行网络发送。队列满时丢弃最旧的增量消息，使实时仿真不会因慢客户端无限堆积内存。对象注册表始终保留最新状态，因此晚连接客户端仍能拿到最新快照。

`stop()` 会通知线程结束，并让发送线程排空已进入队列的数据，然后关闭文件和 Winsock。

## 四、对象生命周期

```text
start()
  └─ addObject(info)
       ├─ update(state)  可重复多次
       └─ removeObject(id, time)
stop()
```

ID 0 是 ACMI 全局对象，业务对象必须使用大于 0 的唯一 ID。未注册对象不能更新；删除后如需重新显示，必须再次注册。

## 五、数据源适配原则

不要把外部协议解析放进核心模块。为每种来源写一个很薄的转换函数：

```cpp
tacview::ObjectState adapt(const UdpPacket& packet) {
    tacview::ObjectState result;
    result.id = packet.trackId;
    result.time = packet.seconds;
    result.longitude = packet.longitudeDeg;
    result.latitude = packet.latitudeDeg;
    result.altitude = packet.altitudeM;
    result.roll = packet.rollDeg;
    result.pitch = packet.pitchDeg;
    result.yaw = packet.headingDeg;
    return result;
}
```

这样 UDP、CSV 或机动模型的变化不会影响 TacviewTCP 核心代码。

## 六、扩展位置

- 新 ACMI 属性：扩展 `ObjectInfo` 与 `AcmiEncoder::objectDefinition()`。
- 新平台网络实现：保留公共头文件，替换 `Tacview.cpp` 的 Winsock 部分。
- 批量帧接口：在门面层增加 `updateFrame()`，内部仍复用队列和编码器。
- 新数据协议：在模块外新增适配器，不修改核心模块。

## 七、测试范围

`tests/TacviewTest.cpp` 验证：

- 文件头与字段编码；
- 文本分隔符清理；
- 服务启动；
- 对象注册和连续更新；
- 对象删除；
- 异步队列在停止前写完；
- 实际 `.acmi` 记录内容。

真实显示测试使用 `examples/TacviewExample.cpp`：先在 Tacview 中启用实时遥测，再运行示例，应看到一架向东飞行的蓝色飞机。
